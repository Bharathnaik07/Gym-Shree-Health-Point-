# 🏋️‍♂️ Shree Health Point

A modern, responsive, and dynamic website for **Shree Health Point (Co-ed Gym)** located in Sirsi, Karnataka. The site features a premium dark-themed design with vibrant neon accents to provide an engaging user experience for current and prospective gym members.

## ✨ Features

- **Hero Section:** High-impact landing area with clear call-to-actions.
- **Interactive BMI Calculator:** Allows users to quickly check their Body Mass Index directly on the site.
- **Services & Programs:** Detailed breakdown of gym offerings (strength training, cardio, yoga, etc.).
- **Pricing Plans:** Clear, tiered membership options.
- **Trainer Profiles:** Introduce the expert fitness coaches.
- **Image Gallery:** Showcase of the gym's equipment and facilities.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Tech Stack

- **HTML5:** Semantic structuring.
- **CSS3:** Custom styling, dark mode aesthetics, neon glow effects, and micro-animations.
- **Vanilla JavaScript:** Interactive elements, BMI calculation logic, smooth scrolling, and mobile navigation.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/shree-health-point.git
   ```
2. Navigate to the project directory:
   ```bash
   cd shree-health-point
   ```
3. Open `index.html` in your favorite web browser. You can also use tools like VS Code's "Live Server" extension for a better development experience.
